Capstone project

Deepfake video detection using deep learning

This application analyzes video frames using a convolutional feature extractor and a recurrent sequence model to identify signs of manipulated content.

Model architecture ResNeXt + LSTM Spatial features and temporal analysis

Project objective

Make video authenticity analysis easier to understand.

Deepfake videos can be difficult to identify through visual inspection alone. This project provides a web-based workflow where users upload a video, select the number of frames to analyze, and receive a REAL or FAKE prediction with a confidence score and frame-level visual context.

System workflow

From upload to prediction

01

Video upload

The user selects a supported video and chooses the sequence length.

02

Frame processing

OpenCV extracts frames and prepares them for model inference.

03

Feature extraction

ResNeXt extracts spatial features from each selected frame.

04

Sequence analysis

The LSTM examines temporal patterns and produces the final prediction.
